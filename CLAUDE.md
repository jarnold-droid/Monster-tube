# CLAUDE.md

This is a browser horror game for a beginner coming from Scratch who is new to JavaScript. The design is in PLAN.md.

## Rules
- **Keep everything in `index.html`**: HTML, CSS and JavaScript all in one file.
- **Put all text and numbers in one `SETTINGS` list at the top** of the script so they're easy to edit. Don't hard-code text or numbers further down.
- **Make small changes**: one feature at a time, following the build order in PLAN.md.
- **Don't add libraries** (or image or sound files) without asking first.
- **Explain each change in 2 or 3 short sentences** in plain words.
- **Always say how to test it**: open `index.html` in a browser, then list exactly what to click or press and what should happen.
